# assertStrict

Source: `lib/assertStrict.js`

Node's `assert/strict`: the strict mode of [assert](assert.md).

```js
import assert from 'assertStrict';

assert.deepEqual({ a: 1 }, { a: 1 });   // deepStrictEqual semantics
assert.equal(1, '1');                   // throws, strictEqual semantics
```

Re-exports everything of `assert` and makes the `strict` function the default export.
