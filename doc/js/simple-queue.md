# simple-queue

Source: `lib/simple-queue.js`

Chromium's `SimpleQueue` as used by the streams specification: a FIFO built from bounded arrays in a linked list, so it does not suffer the scalability problems of one packed array. [stream](stream.md) uses it for its internal queues.

```js
import { SimpleQueue } from 'simple-queue';

const q = new SimpleQueue();
q.push(1), q.push(2);
q.shift();   // 1
q.length;    // 1
```
