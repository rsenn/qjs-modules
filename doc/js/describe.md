# describe

Source: `lib/describe.js`

Lists what a module, an object or a class exports, as nested data, flat lines, JSON or TypeScript declarations. It runs unchanged under qjsm, node, bun and deno (a browser through a companion page), so the same dump can be made of the same API in each runtime and compared. `utilities/api-surface.sh` and `runtime-diff` build on it.

```sh
qjsm lib/describe.js --flat path           # one line per member
qjsm lib/describe.js --dts fs              # declarations
qjsm lib/describe.js --json --global URL
```

Options: `--json`, `--js`, `--dts`, `--flat`, `--sort`, `--no-arguments`, `--class`, `--global`.
