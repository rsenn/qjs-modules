# dbi

Source: `lib/dbi.js`

A light database-independent layer over the [sqlite](../native/sqlite.md), [mysql](../native/mysql.md) and [pgsql](../native/pgsql.md) bindings, after Perl DBI and libdbi: one `Database` and `Result` API whatever the driver.

```js
import { Database } from 'dbi';

const db = await Database.connect('sqlite', 'file.db');   // or { filename } / ':memory:'
const res = await db.query('SELECT * FROM t');

for await(const row of res) console.log(row);
```

`Database.register(name, Adapter)` adds a driver, `Database.connect(driver, options)` opens one: SQLite takes a file name or `{ filename }`, MySQL and PostgreSQL take `{ host, user, password, database, port }`. A `Result` is async-iterable and has `all()` and `fetchFields()`.
