# bun-util

Source: `lib/bun/util.js`

The `Bun.*` utility functions, loaded on the first read of one of them from the [bun](bun.md) global. Names, argument shapes and results follow Bun (checked against bun 1.4.2).

| `Bun.*` | Implemented with |
| --- | --- |
| `deepEquals(a, b, strict)` | own walk, SameValue for primitives |
| `deepMatch(subset, value)` | own walk, arrays must have the same length |
| `inspect(v, opts)` | native `inspect`, `inspect.custom` is Node's symbol |
| `nanoseconds()` | `performance.now()` in nanoseconds |
| `sleep(ms or Date)`, `sleepSync(ms)` | `setTimeout`, `os.sleep` |
| `peek(p)`, `peek.status(p)` | `misc.promiseState`, `promiseResult` |
| `which(cmd, { PATH, cwd })` | a `PATH` walk, executable regular files only |
| `readableStreamTo*` | one reader loop |
| `stripANSI`, `stringWidth` | [terminal](terminal.md) |
| `fileURLToPath`, `pathToFileURL`, `Glob` | re-exported from [url](url.md) and [glob](glob.md) |
