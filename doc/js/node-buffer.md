# node:buffer

Source: `lib/node/buffer.js`

Node's `buffer` module: `Buffer`, its constants, `atob` and `btoa`, as Bun and Deno provide it. `Buffer` is a `Uint8Array` subclass; every byte operation works on the underlying `ArrayBuffer` with absolute offsets.

```js
import { Buffer } from 'node:buffer';

const b = Buffer.from('héllo');           // <Buffer 68 c3 a9 6c 6c 6f>
b.toString('hex');                        // '68c3a96c6c6f'
Buffer.concat([b, Buffer.alloc(2)]).length // 8
```

Encodings: `utf8` (`utf-8`), `utf16le` (`ucs2`), `latin1` (`binary`), `ascii`, `base64`, `base64url`, `hex`.
