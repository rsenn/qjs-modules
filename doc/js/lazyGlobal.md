# lazyGlobal

Source: `lib/lazyGlobal.js`

Defines a global that loads its value from a module on the first read. [node](node.md) and [bun](bun.md) use it for their runtime globals, so nothing is loaded before a script touches it (the web stack costs about 50 ms).

```js
lazyGlobal(globalThis, 'URL', ['lws/url', 'url'], false);
URL;   // loads lws/url if it is in the module path, else url
```
