# database

Source: `lib/database.js`

A thin promise-free wrapper over the [sqlite](../native/sqlite.md) module: `Database` with `prepare()`, `query()`, `run()` and `close()`, and `Statement` with `all()`, `get()`, `iterate()` and `run()` (`bun:sqlite`'s method names).

For a driver-independent API over SQLite, MySQL and PostgreSQL use [dbi](dbi.md).
