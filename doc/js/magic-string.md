# magic-string

Source: `lib/magic-string.js`

A bundled copy of Rich Harris's [magic-string](https://github.com/Rich-Harris/magic-string) with its `sourcemap-codec`: edit a string by index (`overwrite`, `appendLeft`, `remove`, `move`, ...) and generate a source map of the result.

```js
import MagicString from 'magic-string';

const s = new MagicString('problems = 99');
s.overwrite(0, 8, 'answer');
s.toString();            // 'answer = 99'
s.generateMap({ hires: true });
```
