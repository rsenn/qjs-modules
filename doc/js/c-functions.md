# c-functions

Source: `lib/c-functions.js`

Finds C function definitions and prototypes in a C source with the C lexer (`lexer/c.js`, preprocessor directives folded by `lexer/cpp.js`). Used by `nm-symbols`, `source-scanner` and `remove-dead-functions` in `utilities/`.

```js
import { findFunctionDefinitions } from 'c-functions';

for(const f of findFunctionDefinitions(source)) console.log(f);
```

`findFunctionDefinitions(src, filename)` lists the functions with a body, `findFunctionPrototypes(src, filename)` the declarations without one. The default export is `findFunctionDefinitions`.
