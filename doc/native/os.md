# os

Source: QuickJS's own `os` module

The `os` module of QuickJS (files, processes, timers, signals, `Worker`), as extended by qjsm. Not Node's `os`: that is [node:os](../js/node-os.md) and is reached as `node:os`.

See the QuickJS documentation for the semantics of the standard members. The export list below is what this build provides.
