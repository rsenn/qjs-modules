# arraybuffer-sink

Source: `quickjs-arraybuffer-sink.c` — module export: **`ArrayBufferSink`**

An incremental byte accumulator (Bun-style `ArrayBufferSink`): write chunks, then
collect everything as a single `ArrayBuffer`.
