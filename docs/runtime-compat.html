#Runtime compatibility: qjsm against Node, Bun and Deno

Measured 2026-11-03 with qjsm built from b17790ce, against node 23.11.1, bun 1.4.2 and deno 2.9.7. Each cell counts the members (flat names, nested ones such as posix.join included) that the runtime exports out of the members node exports, as listed by utilities/describe.sh --flat --no-arguments. Names only: a method with a different behaviour still counts, behaviour is tested by the @portable tests (tests/unittests/test-*.js also run under node, bun and deno).

Reproduce one row:

for rt in qjsm node bun deno; do utilities/describe.sh -r $rt --flat --no-arguments node:events > /tmp/events.$rt; done

#Bun

Bun has 115 top-level members in bun 1.4.2 and 46 in qjsm, all 46 of qjsm's also in bun. Provided: file(), write(), stdin, stdout, stderr, mmap(), plugin(), Glob, JSON5, JSONC, JSONL, ArrayBufferSink, password, inspect(), deepEquals(), deepMatch(), which(), sleep(), sleepSync(), peek(), nanoseconds(), stringWidth(), stripANSI(), escapeHTML(), concatArrayBuffers(), allocUnsafe(), indexOfLine(), readableStreamTo{Array,ArrayBuffer,Blob,Bytes,JSON,Text}(), fileURLToPath(), pathToFileURL(), gc(), env, argv, main, isMainThread, version, revision, origin, and serve/fetch when qjs-lws is in the module path. See bun and bun-util.

Not provided, among others: Bun.$, spawn()/spawnSync() (use child_process), sql()/SQL, build(), S3Client, RedisClient, CryptoHasher/hash(), gzipSync() and the other compression functions, TOML, YAML, XML, semver, Transpiler, FFI, cron(), color().

#Deno

Deno is a target of the @portable tests for the shared Node-style surface (through tests/deno-import-map.json). Deno.* itself is not implemented.
