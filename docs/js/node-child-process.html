#node-child-process

Source: lib/node/child_process.js

Node's child_process shapes on top of the native child_process: spawn, spawnSync, exec, execSync, execFile, execFileSync, fork, ChildProcess. Loaded for node:child_process; the bare child_process stays the native module.

import { spawn, execSync } from 'node:child_process';

const c = spawn('ls', ['-l']);
c.stdout.on('data', d => {});
c.on('close', (code, signal) => {});

The streams of a child are small EventEmitter objects (data/end, write/end, async iterator), not Node streams: this project does not implement stream.Readable/Writable.
