#node:os

Source: lib/node/os.js — import as node:os (also require('os'), require('node:os')); qjsm only. The bare os stays QuickJS's own os module.

Node's os: facts about the machine, the user and the kernel. On Linux they come from misc.uname(), /proc, /sys and /etc/passwd, read on every call.

import os from 'node:os';

os.cpus().length;          // 8
os.totalmem();             // 33571848192
os.userInfo().username;    // 'roman'
`${os.hostname}`;          // 'gniltag', the getters convert as in Node

Errors have Node's codes: TypeError ERR_INVALID_ARG_TYPE and RangeError ERR_OUT_OF_RANGE for a bad pid or priority, SystemError ERR_SYSTEM_ERROR (ESRCH for a missing process, ENOENT for a user without a passwd entry).
