#node-util

Source: lib/node/util.js

Node's util. Loaded for node:util; the bare util stays qjs-modules' own helper module (util), which this one re-exports except where Node's shapes differ.

import { inspect, format, promisify, parseArgs, styleText } from 'node:util';

Limits:

  • inspect() shows no Proxy target or handler, no Map/Set iterator contents and no WeakMap/WeakSet entries (the engine cannot read them)
  • types.isProxy, isExternal, isKeyObject, isCryptoKey are always false
  • getCallSites() is parsed from Error().stack, scriptId is '0'
