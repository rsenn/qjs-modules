#node

Source: lib/node.js (pure JS, qjsm only) — no exports; qjsm imports it before the script runs, -N (--no-node) turns it off. bun imports it and adds the Bun global; -B loads node alone.

Makes qjsm resolve modules and see the globals the way Node does:

PartWhatFrom
loadersnode:fs and the other node: nameslib/loaders/node.js, see qjsm

// no imports needed under qjsm
Buffer.from('hi').toString('hex');                   // '6869'
global === globalThis;                               // true
const res = await fetch('https://example.com/');     // with qjs-lws installed
  • A global that already exists is never replaced, and assigning one replaces it.
  • The globals read on first use cost nothing at startup: qjsm only checks that the module is a builtin or found by locateModule() (qjs-lws costs ~50 ms to load). Without the module the global is absent: typeof fetch is 'undefined'.
  • process is not part of it: qjsm installs that one itself (-P turns it off).
