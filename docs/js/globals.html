#globals

Source: lib/globals.js — qjsm only; imported by node, which qjsm loads at startup (off with -N)

Installs the web and Node globals QuickJS lacks. A global that already exists is never replaced. Importing the module is the whole API.

import 'globals';

new URL('https://example.com/a?x=1').searchParams.get('x'); // '1'
structuredClone({ d: new Date(0) });
