#bun

Source: lib/bun.js (pure JS) — named exports: plugin, file, write, stdin, stdout, stderr, mmap; the default export is installed as globalThis.Bun by qjsm, on top of node's globals, with the utilities of lib/bun/util.js and Bun.serve/Bun.fetch when qjs-lws is installed (below)

Bun's runtime plugin API (https://bun.com/docs/runtime/plugins), built on registerHooks() (doc/qjsm.md). Only the runtime half exists here: there is no bundler, so onStart/onEnd/onBeforeParse are accepted and ignored.

Bun.plugin({
  name: 'demo',
  setup(build) {
    build.module('virtual', () => ({ exports: { default: 42 } }));
    build.onResolve({ filter: /^yaml:/ }, ({ path }) => ({ path: path.slice(5), namespace: 'yaml' }));
    build.onLoad({ filter: /.*/, namespace: 'yaml' }, ({ path }) => ({ contents: `export default ${JSON.stringify(path)}`, loader: 'js' }));
  },
});

import v from 'virtual';        // 42
Bun.plugin.clearAll();

#Bun.file / Bun.write

const f = Bun.file('data.json');         // path, file: URL or fd; { type } overrides the MIME type
f.size; f.type; f.name; f.lastModified;  // sync stat; 0 / 2**52-1 when missing
await f.text(); await f.json(); await f.bytes(); await f.arrayBuffer();
for await (const chunk of f.stream()) {}
await f.slice(-10).text();               // a window, nothing is read before it is asked
await Bun.write('out/a.txt', 'hi');      // creates parent directories; resolves to bytes written
const w = Bun.file('log.txt').writer();  // FileSink: truncates; write() buffers, flush()/end() write

Bun.file() returns a Blob subclass that reads lazily. Reading a missing file rejects with ENOENT: no such file or directory, open 'x' (code, errno, syscall, path set); a directory with EISDIR; exists() is false for directories. Bun.write takes a string, ArrayBuffer/view, Blob/BunFile, or anything with arrayBuffer(); numbers and objects are stringified like Bun does, null/undefined throw TypeError. Bun.stdin/stdout/stderr are BunFiles over fd 0/1/2 (stdin.size is Infinity).

BunHere
Bun.file(...) is a plain Blob (constructor.name)a BunFile subclass of Blob; instanceof Blob holds
slice(0, 100000).size is 100000clamped to the file size
FileSink.flush() may return a Promisereturns the number synchronously (also fine to await)

#Globals from other modules

Bun is Node-compatible, so lib/bun.js imports node and has every global listed there (fetch, URL, Buffer, Intl, ...). It adds only the Bun object, with two members loaded on first read from qjs-lws (the sibling project ../qjs-lws/) when it is in the module path:

MemberFrom
Bun.serve#serve
Bun.fetch#fetch, the same function as the global fetch
  • Without qjs-lws both are absent: Bun.serve is undefined.
  • -B (--no-bun) makes qjsm load node alone, -N (--no-node) neither.
  • Bun.serve and Bun.fetch are on the Bun object only, not named exports of bun.
