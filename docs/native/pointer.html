#pointer

Source: quickjs-pointer.c — module exports Pointer and DereferenceError

A JSON-Pointer-like path object: an ordered list of atoms (keys/indices) used to address into nested data, with array-style manipulation.

#Pointer

new Pointer(path)   // length 1

path may be a pointer string, an array of keys, or another Pointer.

#DereferenceError

Error subclass thrown when deref fails. Read-only properties: message, pointer, root, pos.
