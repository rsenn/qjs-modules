#mysql

Source: quickjs-mysql.c — module exports MySQL, MySQLError, MySQLResult

Asynchronous MySQL/MariaDB client (wraps libmysqlclient). Connection and query methods are non-blocking and return promises driven off the socket fd.

#MySQL

new MySQL()   // length 1

#Methods

MethodArgsDescription
