#Native Modules

Native C modules (quickjs-*.c) providing direct JavaScript bindings to system functionality.

#Complete List

#Data & Text Processing

  • archive — libarchive reading/writing (tar, zip, cpio, etc.)
  • arraybuffer-sink — Incremental byte accumulator
  • bcrypt — bcrypt password hashing
  • bjson — Native binary object (de)serialization
  • blob — WHATWG Blob API
  • json — JSON read/write and streaming parser
  • lexer — Rule-based lexer/tokenizer
  • list — Doubly-linked list
  • textcode — TextEncoder/TextDecoder (WHATWG Encoding API)
  • xml — XML/HTML parser and writer
  • yaml — Block-YAML writer

#System & I/O

  • child-process — Node.js child_process module
  • directory — Directory iteration
  • gpio — GPIO pin control
  • inotify — Linux inotify file system events
  • location — Source location tracking
  • magic — libmagic content detection
  • misc — System/process/buffer utilities
  • mmap — Memory-mapped files
  • path — Path manipulation
  • serial — Serial port access
  • sockets — BSD sockets
  • syscallerror — System call error codes

#QuickJS Core

  • os — QuickJS's os module as built into qjsm
  • std — QuickJS's std module as built into qjsm

#WebAssembly

  • wasm — WebAssembly JS API over wasm3 or WAMR (Module, Instance, Memory, Table, Global); the WebAssembly global, .wasm loader and WASI are in js/

#Object Manipulation

  • deep — Deep object comparison and cloning
  • inspect — Object inspection and formatting (Node.js util.inspect)
  • pointer — JSON Pointer operations
  • predicate — Type predicates and operator overloading
  • tree-walker — AST/tree traversal

#Streams & Async

  • queue — FIFO queue
  • repeater — Async iteration utilities

#Virtual & Proxy

  • virtual — Virtual property system

#Databases

  • mysql — MySQL client
  • pgsql — PostgreSQL client
  • sqlite — SQLite3 database

#Internal

  • internal — shared support code compiled into other modules, not a standalone module (no JS-facing API of its own)

#Module Naming Convention

Native modules follow the pattern:

  • C source: quickjs-<name>.c
  • JavaScript import: import { ... } from '<name>'
  • Documentation: doc/native/<name>.md
