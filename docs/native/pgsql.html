#pgsql

Source: quickjs-pgsql.c — module exports PGconn, PGerror, PGresult

Asynchronous PostgreSQL client (wraps libpq). Connection and queries run non-blocking against the connection's socket fd.

#PGconn

new PGconn()   // length 1
