#sockets

Source: quickjs-sockets.c — module exports Socket, AsyncSocket, SockAddr, re-exports SyscallError, plus a function list and SOCK_*/AF_*/… constants.

BSD-socket bindings. Socket is the blocking API; AsyncSocket exposes the same surface but its I/O methods return promises.

FunctionArgsDescription
socketpair(domain, type, protocol, out)#4Creates a connected pair of sockets.
select(fds[, timeout])#1select(2) over a set of descriptors.
poll(fds[, timeout])#1poll(2) over a set of descriptors.
